# Lemo-Opuscar for ChatGPT

**An unofficial ChatGPT Skill & Plugin adaptation of Lemo-Opuscar.**

Maintained by **TimNao — AI Skills Lab**.

## Overview

Lemo-Opuscar for ChatGPT adapts LemoLab's code-driven video creation toolkit for compatible ChatGPT and OpenAI Codex workflows.

The project includes 66 visual style guides, video production tools, beginner-friendly documentation, and approval-based workflows.

## Available Packages

- ChatGPT Skill
- ChatGPT Plugin
- English User Guide
- Vietnamese User Guide
- Version Changelogs

Download the installation packages from the **Releases** section.

## Current Version

**v1.0.0-rc.1 — Pre-release**

This release has passed structural and selected component tests. Full end-to-end rendering and installation compatibility across ChatGPT environments have not yet been verified.

Rendering requires a compatible execution environment and additional dependencies.
